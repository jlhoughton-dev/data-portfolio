## 🧠 How I Approach Data & Analysis

I treat analysis as a storytelling and decision-making tool, not just an exercise in pulling numbers. My goal in every project is to translate raw metrics into clear narrative context for decision-makers.

* **Context First:** Data without operational context leads to false conclusions. I start every analysis by aligning metrics with business realities on the ground.
* **Focus on Decision Utility:** A metric is only valuable if it informs an action. I prioritize actionable indicators over vanity metrics.
* **Executive-Ready Communication:** I structure findings using visual hierarchy, executive summaries, and clear recommendations so stakeholders can grasp the core takeaway in under 30 seconds.
